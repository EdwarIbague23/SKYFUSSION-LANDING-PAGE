# SKY FUSSION ANALYTICS

Landing page de **SKY FUSSION ANALYTICS**, una plataforma inteligente para la gestión hídrica, el análisis predictivo y la toma de decisiones institucionales.

## Descripción

La landing presenta la propuesta de valor, problemática, funcionalidades, impacto, tecnologías, modelo de negocio, aliados, equipo y formulario de contacto de la solución.

## Características

- Diseño futurista, responsive y adaptable a móvil, tablet y escritorio.
- Animaciones de entrada, reveals al hacer scroll, hover y microinteracciones.
- Menú hamburguesa responsive con navegación por secciones.
- Dashboard visual con métricas y barras de monitoreo hídrico.
- Contadores animados de impacto.
- Secciones de funcionalidades, tecnologías, modelo de negocio, aliados y equipo.
- Formulario de solicitud de demo.
- Soporte para usuarios con movimiento reducido mediante `prefers-reduced-motion`.

## Tecnologías

- React 19
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
- React Icons

## Instalación

Requisitos: Node.js y npm.

```bash
git clone https://github.com/EdwarIbague23/SKYFUSSION-LANDING-PAGE.git
cd SKYFUSSION-LANDING-PAGE
npm install
```

## Desarrollo

```bash
npm run dev
```

La aplicación estará disponible en la URL local que muestre Vite, normalmente `http://localhost:5173`.

## Build de producción

```bash
npm run build
npm run preview
```

## Publicación en GitHub Pages

El proyecto incluye scripts para generar el build y publicarlo con `gh-pages`:

```bash
npm run deploy
```

## Estructura principal

```text
src/
  components/    Secciones y componentes de la landing
  hooks/         Hooks para contadores y animaciones al hacer scroll
  images/        Logos y fotografías del proyecto
  App.jsx        Composición principal de la página
  index.css      Tema global, responsive y animaciones CSS
```
